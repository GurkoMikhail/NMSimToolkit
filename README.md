# NMSimToolkit (Nuclear Medicine Simulation Toolkit)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-74%20passed-brightgreen.svg)](tests/)

**NMSimToolkit** — современный программный комплекс и интерактивное 3D-приложение для Монте-Карло моделирования систем ядерной медицины (однофотонной эмиссионной компьютерной томографии **ОФЭКТ/SPECT** и позитронно-эмиссионной томографии **ПЭТ/PET**).

---

## Ключевые возможности

* **Высокопроизводительный транспорт фотонов:** Моделирование методом Монте-Карло с алгоритмом отслеживания Вудкока (Woodcock tracking) для быстрых расчетов в высокогетерогенных анатомических фантомах.
* **Физические взаимодействия:** Фотоэлектрическое поглощение, комптоновское рассеяние, рэлеевское рассеяние и рождение пар с сечениями взаимодействия из базы данных материалов.
* **Интерактивный 3D-вьюпорт (PyVista / VTK):**
  * Отображение геометрии коллиматоров, кристаллов детектора и воксельных фантомов.
  * Runtime-трекинг траекторий частиц с цветовой дифференциацией физических процессов в реальном времени.
  * Манипуляторы томографических орбит ОФЭКТ и колец детекторов ПЭТ.
* **3D-визуализация накопления дозы (Volume Rendering):**
  * In-place отображение воксельного энерговыделения без задержек и пересоздания шейдеров GPU.
  * Медицинские палитры псевдоокрашивания (*Hot Iron*, *Rainbow*, *GE Color* и др.) с динамическим отсечением фона.
* **Анализатор результатов и спектрометрия:**
  * Накопление 2D-проекций гамма-камеры в разделяемой памяти (SharedMemory IPC).
  * Энергетический спектр с идентификацией фотопиков радиоизотопов (Tc-99m, I-123 и др.).
  * Построение горизонтальных и вертикальных профилей счета в реальном времени.
* **Декларативная архитектура:** Конфигурирование сцен через человекочитаемые YAML-файлы и инспектор свойств узлов (паттерн MVVM).

## Установка

### Вариант 1: Через `uv` (Рекомендуется)
[uv](https://github.com/astral-sh/uv) обеспечивает быструю установку и гарантирует воспроизводимость зависимостей:
```bash
git clone https://github.com/GurkoMikhail/NMSimToolkit.git
cd NMSimToolkit
uv sync
```

### Вариант 2: Стандартный `pip` и виртуальное окружение
```bash
python -m venv .venv
# Активация окружения (Windows PowerShell):
.venv\Scripts\Activate.ps1
# Активация окружения (Linux / macOS):
# source .venv/bin/activate

pip install -e .
```
Либо установка зависимостей по файлу:
```bash
pip install -r requirements.txt
```

### Вариант 3: Conda / Micromamba
```bash
conda env create -f environment.yml
conda activate NMSimToolkit
```

## Запуск

### 1. Графический интерфейс (GUI)
После установки пакета доступна CLI-команда:
```bash
nmsim-gui
```
Или прямой вызов модуля:
```bash
python -m gui.app
```

### 2. Пакетный расчет через CLI
Для запуска моделирования без графического интерфейса по YAML-конфигурации:
```bash
nmsim-cli nema_1_cam.yaml
# или
python run_simulation.py nema_1_cam.yaml
```

### 3. Клинические сценарии и примеры
В каталоге [`examples/`](examples/README.md) доступны готовые скрипты:
```bash
python examples/brain_main.py        # Томография головного мозга
python examples/heart_main.py        # Сцинтиграфия миокарда (Tc-99m MIBI)
python examples/heart_32_main.py     # 32-проекционная ОФЭКТ миокарда
python examples/lung_cancer_main.py  # Моделирование патологий легких
```

## Структура репозитория

```
NMSimToolkit/
├── core/                # Вычислительное ядро Монте-Карло, физика, геометрия, HDF5
├── gui/                 # MVVM-архитектура графического интерфейса (PySide6 / VTK)
│   ├── controllers/     # Контроллеры фоновых потоков и IPC-опроса
│   ├── viewmodels/      # ViewModels графа сцены и инспектора свойств
│   ├── views/           # Главное окно, инспектор свойств, просмотр результатов
│   └── viewport_3d/     # 3D-вьюпорт, рендереры треков, дозы и манипуляторы
├── docs/                # Техническая документация, планы архитектуры и аудиты
├── examples/            # Скрипты клинических сценариев моделирования
├── phantoms/            # Цифровые анатомические и тестовые фантомы (NEMA, Hoffman)
├── presets/             # Базовые пресеты параметров и геометрии
├── tests/               # Полный набор модульных и интеграционных тестов
├── environment.yml      # Конфигурация Conda-окружения
├── pyproject.toml       # Метаданные пакета, зависимости PEP 621 и настройки инструментов
├── requirements.txt     # Зависимости для pip
├── requirements-dev.txt # Зависимости для разработки и тестирования
└── run_simulation.py    # Точка входа для запуска CLI
```
