# Примеры использования (Examples)

В этом каталоге собраны клинические сценарии и примеры моделирования для ядерной медицины (ОФЭКТ):

- **`brain_main.py`** — Моделирование ОФЭКТ головного мозга (Brain SPECT) со сканированием по орбите и регистрацией в логах.
- **`heart_main.py`** — Моделирование ОФЭКТ миокарда (Myocardial Perfusion SPECT) с радиофармпрепаратом Tc-99m MIBI и воксельным фантомом сердца.
- **`heart_32_main.py`** — Сценарий томографического сканирования миокарда на 32 угловых проекциях с использованием параллельных гамма-камер.
- **`lung_cancer_main.py`** — Сценарий моделирования накопления изотопов при новообразованиях легких.

### Запуск примеров

Из корневой директории репозитория:
```bash
python examples/brain_main.py
python examples/heart_main.py
python examples/heart_32_main.py
python examples/lung_cancer_main.py
```
