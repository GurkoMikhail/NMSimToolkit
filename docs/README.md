# Техническая документация NMSimToolkit

Добро пожаловать в репозиторий технической и архитектурной документации программного комплекса **NMSimToolkit** — высокопроизводительного пакета для физико-математического моделирования методами Монте-Карло приборов ядерной медицины (ОФЭКТ, ПЭТ, дозиметрия).

---

## 📚 Основные разделы документации

Вся действующая архитектурная и инженерная документация поддерживается в актуальном виде и сгруппирована по доменам:

1. **[Архитектура расчетного ядра (`core_architecture.md`)](core_architecture.md)**
   * Data-Oriented Design (DoD) и упаковка частиц в Structure of Arrays (SoA);
   * Разделение горячих (`ParticleState`) и холодных данных;
   * Трассировка Вудкока (Woodcock Tracking) и Single-Pass Painter's Algorithm;
   * Компиляция плоской геометрии (`GeometryCompiler`) и физических процессов (`PhysicsCompiler`);
   * Асинхронный конвейер записи взаимодействий (`DataManagerSoA`) в HDF5.

2. **[Архитектура графического интерфейса (`gui_architecture.md`)](gui_architecture.md)**
   * Паттерн MVVM (Model-View-ViewModel) и медиаторы сессий (`SceneViewportController`, `OrchestratorSession`);
   * Принцип единого источника истины (Single Source of Truth, SSOT) для параметров расчета;
   * 3D-интерактивный вьюпорт на базе VTK/PyVista и UE-Style манипулятор (`TransformGizmo`);
   * Архитектура межпроцессного взаимодействия (IPC) и потоковая телеметрия.

3. **[Кинематическая система и детекторы (`kinematic_system.md`)](kinematic_system.md)**
   * Физическая модель гамма-камеры (`GammaCamera`): размер активного поля, толщины слоев;
   * Кинематика станины томографа (`GantryNode`) и расчет орбитальных траекторий ОФЭКТ/ПЭТ;
   * Контракт кинематических ограничений (`IKinematicConstraint`);
   * Синхронизация 3D Gizmo, панели инструментов и инспектора свойств (`PropertyInspector`).

4. **[Архитектурный бэклог проекта (`architecture_backlog.md`)](architecture_backlog.md)**
   * Реестр отложенных архитектурных решений, планов оптимизации и долгосрочных улучшений (согласно Правилу №11 проекта).
