# Контрольный чек-лист приемки (QA Checklist)
## Реализация диалога импорта воксельных распределений и универсального маппинга

Данный документ фиксирует статус верификации и тестирования компонентов, реализованных в рамках задачи интеграции диалогового окна импорта сырых (`.dat`, `.raw`, `.bin`) и контейнерных (`.npy`) файлов распределений с поддержкой вещественных значений (`float`) и синхронизации источников.

---

### 1. Архитектурные требования и стандарты кодовой базы
- [x] **Чистое разделение `core/` и `gui/`:**
  - В каталоге `core/` отсутствуют импорты графических библиотек (`PySide6`, `VTK`, `matplotlib`).
  - В `core/data/distribution_loader.py` добавлен метод `inspect_metadata()`, возвращающий чистый словарь метаданных без UI-сущностей.
- [x] **Запрет утиной типизации (`hasattr`, `getattr`, `setattr`):**
  - Во всех новых и модифицированных классах взаимодействия ведутся через явные свойства и методы интерфейсов.
- [x] **Именование идентификаторов:**
  - Полное отсутствие однобуквенных переменных (за исключением счетчиков циклов `row_idx`, `dim_idx`). Цвета именованы явно (`red, green, blue`).
- [x] **Конвенция физических единиц:**
  - Все длины выражены в миллиметрах (`units.mm`), энергии в кэВ/МэВ, активность в МБк. Имена полей не содержат суффиксов размерностей (`voxel_size`, `activity`, `noise_threshold`).
- [x] **Принцип LBYL (Look Before You Leap) и строгие исключения:**
  - Валидация положительных размеров сетки и шагов вокселей в `DistributionImportParameters.__post_init__`.
  - Динамическая блокировка кнопки «ОК» в UI при несовпадении байтового размера сырого файла с расчетным (`expected_bytes == actual_bytes`).
- [x] **Окружение:**
  - Тестирование выполнено строго через `.venv\Scripts\pytest.exe`.

### 2. Реализованные компоненты

#### 2.1. Модель данных (`gui/models/distribution_import_params.py`)
- [x] Перечисление `ImportTargetKind` (`PHANTOM`, `SOURCE`).
- [x] Строгий датакласс `DistributionImportParameters` с поддержкой `shape`, `order`, `dtype`, `encoding`, `voxel_size`, `mapping`, `material_mapping`, `fill_value`, `total_activity`, `noise_threshold`.
- [x] Валидация инвариантов геометрии и файловых путей.

#### 2.2. Быстрая инспекция метаданных (`core/data/distribution_loader.py`)
- [x] Метод `DistributionLoader.inspect_metadata(file_path)` считывает заголовок `.npy` без загрузки всего трехмерного массива в оперативную память.
- [x] Корректно определяет размер файла на диске для сырых бинарных файлов (`.raw`, `.dat`, `.bin`).

#### 2.3. Универсальное диалоговое окно (`gui/views/distribution_import_dialog.py`)
- [x] **Блок 1: Формат сырых данных:**
  - Ввод размерности ($N_x \times N_y \times N_z$).
  - Выбор порядка развертки: Fortran ('F') / C ('C').
  - Выбор типа данных (`float32`, `float64`, `int16`, `uint16`, `int32`, `uint8`).
  - Режим кодирования: бинарный / текстовый ASCII.
  - LBYL-индикатор валидации байтового объема файла с цветовой индикацией.
- [x] **Блок 2: Геометрия сетки:**
  - Независимый ввод шага вокселей ($S_x, S_y, S_z$) для фантома.
  - Ввод шага вокселя для источника.
  - Расчет реальных физических габаритов объема в мм.
  - Для источника: кнопка «⇲ Скопировать геометрию фантома сцены» для моментальной синхронизации.
- [x] **Блок 3: Специализированная настройка:**
  - **Для фантома:**
    - Кнопка автосканирования уникальных вещественных меток (`_on_auto_scan_materials`).
    - Таблица маппинга: Вещественное значение / ID $\rightarrow$ Число вокселей $\rightarrow$ % объема $\rightarrow$ Цвет $\rightarrow$ Материал NIST.
    - Выбор материала фона по умолчанию (`fill_value`): установлен `Air, Dry (near sea level)` вместо Vacuum; Вакуум полностью исключен из дефолтных списков.
    - Кнопки ручного добавления и удаления строк маппинга.
  - **Для источника:**
    - Поле ввода суммарной активности (МБк).
    - Порог отсечения фонового шума (`noise_threshold`).
    - Кнопка инспекции распределения активности с расчетом динамического диапазона и доли активных вокселей.

#### 2.4. Поддержка нецелочисленных данных (Float values)
- [x] `gui/viewmodels/nodes/voxel_volume_vm.py`:
  - Метод `reload_distribution()` принимает произвольный словарь `mapping: Dict[float, str]`.
  - Устранено приведение к целочисленному типу `data.astype(int)`.
  - Поиск меток реализован через `np.isclose(data, float_key, atol=1e-5)` с сохранением физической точности.
- [x] `gui/viewmodels/nodes/source_vm.py`:
  - Расширен метод `reload_distribution()` для поддержки параметров формы, порядка, типа данных, шага вокселей, активности и фильтрации шума.

#### 2.5. Интеграция с PropertyInspector (`gui/views/property_inspector.py`)
- [x] Замена прямого вызова `QFileDialog` на запуск модального диалога `DistributionImportDialog` в `_on_browse_phantom_file()`.
- [x] Интеграция `DistributionImportDialog` в `_on_browse_source_file()` с автоматическим поиском узла фантома на сцене.
- [x] Реактивное обновление спинбоксов вокселей, текстовых полей путей, меток габаритов и таблицы маппинга материалов.
